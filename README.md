# tesis-mater
Modelo de simulacion de transacciones dentro del MATER/MATE para contratos entre privados. Modelo de optimizacion con programacion lineal para maximizar margenes.

La clasificacion del cumplimiento contractual anual usa una tolerancia absoluta de 1 MWh para minimos y maximos de clientes y para TOP de generadores. La tolerancia solo afecta los indicadores y estados de cumplimiento: no modifica las energias reales, las penalidades economicas ni las restricciones del solver.
